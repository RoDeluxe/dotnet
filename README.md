Repositorio de **prácticas de .NET**. Contiene el proyecto `Demo` de **ASP.NET Core MVC** (Razor views, layout, controladores) del curso.

## 📦 Descargar
El proyecto viene empaquetado: [`dotnet.zip` en Releases](https://github.com/RoDeluxe/dotnet/releases) (4 MB).

## 🗂 Contenido del zip
```
dotnet/Demo/
├── Views/            vistas Razor (_Layout, páginas, Error)
├── Controllers/      controladores MVC
├── Models/           modelos
├── appsettings.json  configuración
└── ...
```

## 🔧 Cómo correrlo
```
dotnet restore
dotnet run        # dentro de la carpeta dotnet/Demo
```
